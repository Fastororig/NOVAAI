# Nova AI — Легковесный нативный Android-клиент для Google Gemini API

Нативное приложение на **Kotlin** и **Jetpack Compose**, созданное по образцу ReOldAi, оптимизированное для стабильной и быстрой работы на слабых устройствах и старых версиях Android (начиная с Android 7.0 Nougat, API 24).

---

## ⚡ Особенности и архитектура
- **Минимальная версия**: Android 7.0 (API 24).
- **Автоматическая загрузка моделей**: Прямой запрос `GET https://generativelanguage.googleapis.com/v1beta/models?key={apiKey}` с поддержкой всех страниц через `nextPageToken`.
- **Фильтрация и точность**: Отбираются только модели с `supportedGenerationMethods: ["generateContent"]`. Для запросов генерации используется точный `cleanId` из ответа API без выдуманных названий.
- **Группировка по семействам**: Модели автоматически распределяются по категориям:
  - **Семейство Flash** (сверхбыстрые, легковесные)
  - **Семейство Pro** (глубокие рассуждения и логика)
  - **Другие модели**
- **Рекомендуемая модель**: Модель `gemini-3.8-flash` помечается как рекомендуемая, только если она фактически присутствует в ответе API от Google.
- **Отказоустойчивый кэш**: Список моделей и выбранная модель сохраняются локально. При сбое сети кэш не удаляется — выводится информативное предупреждение.
- **Сетевой стек**: OkHttp 4.12.0 с автоматической поддержкой TLS 1.2+ и строгим `network_security_config.xml` (HTTPS только к официальным серверам Google).
- **Безопасность API-ключа**: Ключ вводится пользователем в настройках, хранится исключительно локально в изолированном хранилище приложения (`EncryptedSharedPreferences` с отказоустойчивым fallback) и передается **напрямую** в официальный REST API `https://generativelanguage.googleapis.com/v1beta/models/...:generateContent`.
- **Поддержка отправки файлов (Мультимодальность)**: Кнопка-скрепка для выбора нескольких файлов (изображения JPG/PNG/WebP, PDF, TXT, CSV, JSON, MP3, WAV, MP4). Файлы до 20 МБ передаются как `inline_data` (Base64), файлы свыше 20 МБ — через Gemini Files API (`upload/v1beta/files`).
- **Интерфейс**: Тёмная палитра (OLED Dark) без тяжелых шейдеров и размытий, горизонтальная панель вложений с миниатюрами и крестиками удаления, идеальная плавность даже на телефонах с 2 ГБ ОЗУ.
- **Поддержка Markdown**: Встроенный парсинг списков, заголовков, блоков кода с подсветкой и кнопкой быстрого копирования в буфер обмена.
- **Обработка ошибок**: HTTP 400 (неверный ключ), 403 (доступ закрыт), 404 (модель недоступна), 413 (превышение размера), 429 (лимиты квот), 500/503 (перегрузка серверов) и сетевые сбои с кнопкой "Повторить".

## 🔑 Начало работы
1. Запустите приложение на телефоне.
2. Откройте **Настройки** (иконка шестерёнки вверху).
3. Вставьте ваш ключ Google Gemini API (получить бесплатно можно на [aistudio.google.com](https://aistudio.google.com)).
4. Нажмите **Сохранить** и начинайте общение!
